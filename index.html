Paste in Gmail

  1. Open your signature settings

    Gmail → ⚙ Settings → See all settings → General → Signature

  2. Replace the old one

    Select your OTTO signature (or Create new), click in the box, Cmd A, delete, then Cmd V.

  3. Set it as default

    Under Signature defaults, pick it for new emails and for reply/forward.

  4. Save and test

    Scroll down, click Save Changes, send yourself a mail and check the banner moves.

Paste shows code instead of your signature?
  1. Select all the code below and copy it.
  2. Open the w3schools editor, clear the left side, paste, click Run.
  3. Click in the right side, Cmd A, Cmd C, and paste that in Gmail.
